## Mercury — Investment Platform

**Project:** Mercury — a responsive web application for multi-asset investment management.

**Scope:** Frontend development for a platform supporting real estate, crypto, retirement plans, long/short-term investments, agro farming, and task-based refund investments.

**Key Features**
- Multi-category investments (Real Estate, Crypto, Retirement, Long/Short, Agro Farming, Task Refund)
- Real-time investor dashboard (auto-refresh hourly)
- Portfolio tracking with price movement indicators
- Flexible user registration (phone, email, WhatsApp, Facebook)
- Region-specific address selection (Nigerian/African LGAs)
- Blog with investment-plan participation metrics

**Current Phase:** Frontend Development
**Status:** In Progress
- Frontend framework selection and setup

- Development environment configuration

## Site Structure

- **Homepage:** Overview, featured plans, testimonials  
- **Investment Categories:** Pages for each asset type (benefits, risks, plans)  
- **Dashboard:** Personalized portfolio, performance, alerts, stats  
- **Admin Panel:** User & investment management, transaction monitoring, analytics  
- **Blog:** Articles, market trends, plan participation metrics  
- **Support:** FAQ, contact form, live chat, support resources  
- **Settings:** Profile, notification preferences, security and KYC options
